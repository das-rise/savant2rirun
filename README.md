# savant2rirun

A command-line tool to convert vehicle trajectories from [SAVANT's OpenLabel](https://github.com/RI-SE/SAVANT/tree/main/schema) format to a set of CSV files compatible with [RiRun](https://github.com/das-rise/rise-carla-runner). 

> [!NOTE]
> This open source project is maintained by [RISE Research Institutes of Sweden](https://ri.se/). See license file for open source license information.

## Installation

Requires Python **≥ 3.12**. With [uv](https://docs.astral.sh/uv/) installed:

```bash
uv sync
```

This will create a virtual environment and install the package with all dependencies (including `orbit-georef` from GitHub).

## Usage

Activate the virtual environment first, then run the tool:

```bash
source .venv/bin/activate
```

```bash
savant2rirun [OPTIONS] <openlabel_file> <georef_file> <outpath>
```

### Arguments

*   `openlabel_file`: Path to the OpenLabel `.json` file to process.
*   `georef_file`: Path to a georeference file (`.json`) generated by [orbit-georef](https://github.com/RI-SE/ORBIT/tree/main/orbit-georef).
*   `outpath`: Directory where the generated trajectory files will be saved.

### Options

*   `--start_frame <FRAME>`: The starting frame number to parse. Defaults to the beginning of the OpenLabel file.
*   `--end_frame <FRAME>`: The ending frame number to parse. Defaults to the end of the OpenLabel file.
*   `--proj <PROJ_STRING>`: The projection string to use for converting pixel coordinates to geographic coordinates (e.g., `EPSG:3006` for SWEREF99 TM). If omitted, a `WGS84` projection will be used.
*   `--offset <X> <Y>`: An optional (x, y) offset to apply to the coordinates after conversion. Defaults to `(0, 0)`.
*   `--framerate <FPS>`: The framerate of the recordings in the OpenLabel file at `openlabel_file`.
*   `--use-dataprov`: Enable [dataprov](https://pypi.org/project/dataprov/) to create a provenance chain (a JSON file) alongside the output, documenting the conversion's inputs, outputs, and parameters.
*   `--dataprov-input-provenance-files <FILES...>`: Paths to existing dataprov provenance files to link as inputs (in order: OpenLabel, georef). Use `None` to skip either. Only used when `--use-dataprov` is set.

### Example

```bash
savant2rirun data/savant_output.json data/georef.json trajectories/ --proj "EPSG:3006"
```

## Output

The tool generates a CSV file for each vehicle trajectory. The files are named `vehicle_<ID>_<TYPE>.csv` (where `<TYPE>` indicates vehicle type). Each file contains the following columns:

*   `x_loc [m]`: The x-coordinate of the vehicle.
*   `y_loc [m]`: The y-coordinate of the vehicle.
*   `Time [s]`: The timestamp of the measurement, calculated from the framerate of the recording device.
*   `Heading [deg]`: The heading of the vehicle in degrees.

## Dependencies

*   [rich-argparse](https://github.com/hamdanal/rich-argparse)
*   [pyproj](https://pyproj4.github.io/pyproj/stable/)
*   [orbit-georef](https://github.com/RI-SE/ORBIT/tree/main/orbit-georef) (part of the ORBIT project)
*   [dataprov](https://pypi.org/project/dataprov/) (optional provenance tracking, used with `--use-dataprov`)
